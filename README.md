# Chat Windows — Fabric 1.21.11

Клиентский Fabric-мод для Minecraft **1.21.11**, который разделяет чат по отдельным окнам с фильтрами.

## Что уже сделано

- Отдельные окна чата поверх HUD.
- Для каждого окна свои ключевые слова.
- Если сообщение содержит ключевое слово, оно попадает в нужное окно.
- У каждого окна отдельно включается режим: скрывать сообщение из основного чата или оставлять копию в основном чате.
- Окна можно перемещать мышкой за заголовок.
- Окна можно изменять по размеру за нижний правый угол.
- Настройки сохраняются в `config/chatwindows.json`.
- Есть готовые стандартные окна: чат персонала, жалобы/репорты, подозрительные слова.
- Есть GitHub Actions сборка, которая сама выдаёт `.jar` в Artifacts.

## Управление

- **Right Shift** — открыть редактор окон.
- В редакторе:
  - `+ окно` — создать новое окно.
  - `сохранить` — сохранить настройки.
  - `сброс` — вернуть стандартные окна.
  - `скрывать из основного: да/нет` — если `да`, найденное сообщение не будет показано в обычном чате.
  - `режим фильтра: любое слово/все слова` — окно принимает сообщение по одному ключевому слову или только если найдены все слова.
  - ключевые слова вводятся через запятую: `репорт, жалоба, report`.

## Как собрать через GitHub

1. Создай новый репозиторий на GitHub.
2. Загрузи туда все файлы из этого проекта.
3. Открой вкладку **Actions**.
4. Запусти workflow **Build Fabric Mod**.
5. После сборки скачай `.jar` из **Artifacts**.
6. Положи `.jar` в папку `mods` клиента вместе с Fabric API.

## Как собрать локально

Нужны Java 21 и Gradle 9.2+.

```bash
gradle build --no-daemon --stacktrace
```

Готовый `.jar` будет тут:

```text
build/libs/chatwindows-fabric-1.21.11-1.0.0.jar
```
